# Ankieta projektu

Skup się tylko na odpowiedziach. Nagłówek i status obsługuje agent.

Wypełnij **wszystkie** pola. Pisz konkretnie: nazwy plików, liczby, przykłady. Odpowiedź „różnie” albo „zależy” agent odeśle z prośbą o przykład. Jeśli czegoś nie wiesz, napisz „nie wiem”, a agent zaproponuje rozwiązanie.

Gdy skończysz, napisz agentowi: **„Skończyłem”**.

---
